# Papper brand assets

These assets use the Papper wordmark style from the supplied reference image and the project brand color `rgb(29, 52, 71)` (`#1D3447`).

## Files

- `papper-wordmark.png`: transparent dark wordmark for light backgrounds, 1600 × 608.
- `papper-wordmark-light.png`: transparent warm-white wordmark for dark backgrounds, 1600 × 608.
- `papper-icon.png`: transparent dark capital-P icon, 1024 × 1024.
- `papper-icon-light.png`: transparent warm-white capital-P icon for dark backgrounds, 1024 × 1024.
- `papper-app-icon.png`: square `#1D3447` app icon with the warm-white P, 1024 × 1024.
- `papper-app-icon-512.png`, `papper-app-icon-256.png`, `papper-app-icon-128.png`, `papper-app-icon-64.png`, `papper-app-icon-32.png`, `papper-app-icon-16.png`: ready-to-use app icon sizes.
- `papper.ico`: Windows icon containing 256, 128, 64, 48, 32 and 16 pixel layers.
- `papper-wordmark-preview.png` and `papper-icon-preview.png`: neutral-background previews for documentation.
- `sources/`: opaque model outputs retained as the editable source reference for the delivered assets.

The wordmark spelling is exactly `Papper`. The icon is the same oversized capital `P` used by the wordmark.
