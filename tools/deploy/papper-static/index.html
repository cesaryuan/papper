Papper

用 Markdown 写论文，用 Word 交稿。

将 Markdown 稿件构建为 Word 文档，处理参考文献、图表与公式编号，以及审稿回复。

安装

无需预装 Python 或 uv，无需管理员权限。自动检测公网 IP：中国 IP 使用 CERNET 镜像，其他地区使用官方 PyPI，校验 SHA-256 后安装到当前用户目录。

Windows x64 · PowerShell

irm https://papper.cesaryuan.top/install.ps1 | iex

Linux x86_64 / macOS Apple Silicon · 终端

curl -fsSL https://papper.cesaryuan.top/install.sh | sh

Linux 需要 glibc 2.28 及以上、curl 和 unzip；macOS 需要 14 及以上。Windows 请使用 64 位 PowerShell 5.1 或更新版本。

安装完成后打开新终端，运行 papper --version。再次运行安装命令即可升级。

查看 PowerShell 脚本 · 查看 Shell 脚本 · 指定版本、切换镜像与卸载

已经安装 uv？

uv tool install papper

两种安装方式任选其一。若迁移到独立安装，先运行 uv tool uninstall papper，避免 PATH 中出现多个版本。

指定版本、镜像、安装目录与卸载

Windows 可先设置环境变量，再运行安装命令。例如指定版本、使用官方 PyPI：

$env:PAPPER_VERSION = '0.11.3'
$env:PAPPER_INDEX_URL = 'https://pypi.org/simple'
irm https://papper.cesaryuan.top/install.ps1 | iex

Linux / macOS 可以向脚本传参：

curl -fsSL https://papper.cesaryuan.top/install.sh | sh -s -- --version 0.11.3 --index-url https://pypi.org/simple

两种脚本都支持 PAPPER_VERSION（默认 latest）、PAPPER_INDEX_URL（手动指定索引后跳过 IP 检测）、PAPPER_INSTALL_DIR（绝对安装路径）和 PAPPER_NO_MODIFY_PATH=1（不配置 PATH）。镜像地址应使用以 /simple 结尾的索引地址。

自动检测依次查询 Cloudflare trace 和 IPinfo，每次请求设置 2 秒超时；只有国家代码为 CN 才使用 https://mirrors.cernet.edu.cn/pypi/web/simple，其他地区或检测失败使用官方 PyPI。自动选择的镜像索引不可用时也会回退官方源。检测反映当前网络出口，代理 / VPN 会影响结果。

默认安装到 Windows 的 %LOCALAPPDATA%\Programs\Papper 或 Linux / macOS 的 ~/.local/share/papper。自定义目录升级时须使用同一个目录。校验失败不会切换现有版本，历史版本保存在安装目录的 releases 下。

卸载时删除安装目录，并从 Windows 用户 PATH 或安装时提示的 shell 配置文件中移除该目录的 bin 条目。稿件目录和 ~/.papper 运行缓存会保留。

目前不提供 Linux ARM64、Alpine / musl、Intel Mac 和 Windows ARM64 原生安装包。

开始写作

papper init my-paper
cd my-paper
papper build docx

打开 output/docx/manuscript.docx 查看结果。
