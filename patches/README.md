# MathType safe Rust API

`mathtype-rust-safe-api.patch` records the small public API addition to the
`scripts/mathtype-rust` repository, based on upstream commit
`9fda5da1cdaa17b0d03078e69eb825b952625283`. Its parsing, MTEF/OLE encoding, CLI,
and optional C ABI behavior are unchanged. Default preferences now use
`include_str!` to embed the existing `.eqp` file, removing an accidental runtime
dependency on the developer's absolute source directory. The three existing
preference tests independently compare generated bytes with the historical
installed fallback and exercise size/font changes; explicit preference files
and their failure behavior remain supported.

The parent checkout pins local API commit
`a4ac2700a24467a779d51215ad830818d559d3f5` on the `papper-safe-api` branch.
That commit contains this patch and is available locally; it has not been pushed.

The new API exposes owned `EquationPayload` artifacts, `encode_latex`,
`mtef_from_ole`, and `decode_ole` with `DecodeMode`. Papper depends on the real
crate and calls these Rust APIs directly; it neither imports private modules
nor rewrites dependency sources during compilation. `latex2wmf` uses the same
fixed git revision in both consumers, so Cargo links one renderer.

For review:

```powershell
git -C scripts/mathtype-rust diff 9fda5da1cdaa17b0d03078e69eb825b952625283 -- src/lib.rs src/mtef/fixed_defs.rs
git -C scripts/mathtype-rust apply --reverse --check ../../patches/mathtype-rust-safe-api.patch
```

To apply to a checkout at the **old base commit**, before building:

```powershell
git -C scripts/mathtype-rust apply --check ../../patches/mathtype-rust-safe-api.patch
git -C scripts/mathtype-rust apply ../../patches/mathtype-rust-safe-api.patch
```

Do not apply the patch a second time to a checkout whose API commit already
contains it. A release or fresh remote checkout must make the MathType API
commit reachable in its upstream repository **before** publishing the parent
commit that pins it. A local commit is sufficient for this working tree, but
does not establish remote availability. The patch is a review aid and manual
reconstruction record, not a hidden build-time patch step.

Equation caches now use `native-v2` and a build-time content fingerprint covering
the engine sources, embedded renderer assets, integration, dependency lock, and
target. User font files, preferences, and the optional C# helper retain their
individual runtime content digests. Whole DLL hashing and runtime source scans
are removed, including when all equation artifacts are already cached.
